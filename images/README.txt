IMMAGINI ORIGINALI / FILM STILLS

reel.webp
eva-01.webp
ordinary-psychos.webp
white-fly.webp
il-manutentore.webp

Dimensioni consigliate: 1920x1080, rapporto 16:9, qualita WebP 82-88.
Il sito mostra automaticamente il fotogramma quando presente. Se manca, conserva la miniatura YouTube originale.
Non sovrascrivere i file JS o CSS per cambiare le immagini.
